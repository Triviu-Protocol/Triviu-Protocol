Lesson 06 · Run it yourself

Now do it — in the order that makes mistakes free.

The simulator shows both sides

It puts the possibility — a single cycle that clears and profits — next to the long-run reality — the average outcome once the fee wall, slippage and competition are applied over many attempts. Both are true at once, and that is the honest picture: a win can exist while the expected result is still zero. Possibility is not probability.

Running without idle capital

You don't need your own float to run a cycle: a flash loan borrows and repays inside the same atomic transaction. On the target chains, Aave v3 charges a 0.05% premium with repay-or-revert atomicity; Balancer's Vault currently charges no protocol fee. Useful — but the premium is not free money: it is one more cost added to the fee wall the cycle has to clear. It changes who provides the capital, not whether the edge exists.

That was the whole point

Triviu never promised you a profit. It promised you could verify — the math, the code, the odds — and decide for yourself. You now know why the honest expected result for an individual is usually zero, and you can prove every step of that yourself, from public data. That capability, not a number, is the product.
