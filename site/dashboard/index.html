The public record, failures included.

A metric without its failure context is marketing; a metric with failures included is evidence. This dashboard will publish every execution — the reverts and the losses alongside the wins — because that is the only honest way to show what atomic arbitrage actually does.

Where this stands

Four contracts are live on Polygon (chain 137) since 12 August 2026 — the ParameterRegistry, the Executor, the Gas-Tank and the LP Vault — with ownership and treasury held by a Safe, and the source verified on Polygonscan. Arbitrum and BSC are not deployed. This page still plots nothing, and here is the honest reason: no cycle has been executed yet. That is an empty history, not a missing chart. Triviu invents no numbers, and a chart with plausible lines drawn over no data would be exactly that invention. It fills in from public on-chain data, per chain, with failures included from the first block. Reverted transactions still pay gas.

It goes live with the first deployment — per chain.

The SQL that will feed it is already public and versioned — don't trust, read it: revert rate · executions by route · gas vs net result · treasury balance. The full dashboard spec — panels, rules, timing — is public too.
