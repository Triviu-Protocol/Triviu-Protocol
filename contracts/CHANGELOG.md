# Changelog

Format from [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). Versions follow
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

**Nothing here has been released.** No version is tagged, no contract of this line has ever been
deployed to a public network — `deployments/` holds only `999999.json`, the local chain — and the
protocol is under a security block that has not been lifted. The entries below are the record of
what changed, not an invitation to use it.

## [Unreleased]

### Security

- **The vault only hands its input to a curated executor.** `VaultExecution._swap` transfers
  `amountIn` to `p.executor` before the route runs, and `p.executor` is a field whoever submits the
  execution fills in. Nothing checked that address against any list, so the submitter chose who
  received the funds. Measured with the check absent, on a buy of 100 base units through an executor
  that keeps what it receives: 100.5 left the vault, 0 came back, and the transaction succeeded.
  `ProtocolRegistry` now curates executors — `isExecutor` / `setExecutor` — and `_checkRoute` reads
  the curation on **every** execution rather than at configuration time, so an executor withdrawn by
  governance stops being accepted on the next call. Enforced on both entrypoints, the operator's
  `execute` and the owner's `executeAsOwner`.

- **The example strategy no longer ships without a buy floor.** On a buy there are three floors and
  only one belongs to the owner: `Limits.minRatioBps` compares the *declared* `minOut` and never the
  realised amount, and `operatorMinOut` is declared by whoever submits. What is left is
  `Intent.minOut`, from the owner's `Strategy` — and `ExampleStrategy` declared zero there, so a
  vault built from the reference flow accepted a route that returned nothing. `ExampleStrategy` now
  takes `MIN_OUT_PER_TICKET` by constructor and **refuses zero**; a partial ticket demands a
  proportional share, **rounded up**.

- **The buy floor no longer rounds away to zero.** The first version of the fix above rounded the
  proportional share down, so the floor still reached exactly zero whenever
  `MIN_OUT_PER_TICKET × amountIn < TICKET` — with a floor of `1`, on every partial buy up to a whole
  ticket minus one unit. The constructor's refusal of zero was a check that could be satisfied
  without protecting, and it invited exactly that: `1` is what someone types to get past it. Now
  rounded up, so any non-zero floor stays non-zero for any non-zero amount.

- **`MIN_RATIO_BPS` lost its silent default.** Two scripts read it through `vm.envOr` with a
  fallback of `0`, which disables the ratio floor, so a vault built by following the README had it
  off without the owner ever seeing the decision. Both now require it to be declared. Zero remains a
  valid answer; it is no longer an unspoken one.

### Fixed

- **CI had never been green.** `forge build --sizes` reports every contract, and it already drops
  those inheriting `Test`/`Script`. The invariant `Handler` inherits neither by design — the runner
  calls its functions directly — so its 52,502 bytes of initcode entered the report and exceeded the
  EIP-3860 limit, failing that step on every push. The size gate now skips `test/**`, which is the
  scope the limit describes: what reaches a chain. Test compilation is not lost, since `forge test`
  builds them in the next step.

- **The trust model claimed the operator cannot move funds.** It now states what the operator can
  still do: author a route that nothing on-chain prices.

- **The standalone actions table listed file names under a sentence promising a `--tc`.** The file
  name is not the contract name, so the natural guess failed. Both columns are now present.

### Added

- `.env.example`, which `README.md` had told the reader to copy since before it existed. Written
  from the variables the scripts actually read.
- `.gitattributes` pinning LF. `solc` hashes the source text into the contract metadata, so a clone
  checked out with CRLF verifies differently on a block explorer than one checked out with LF, and
  the cause is invisible in a diff.
- `abi/`, regenerated by `sh script/abi.sh` and checked for staleness in CI.
- `CONTRIBUTING.md`, `SECURITY.md`, `slither.config.json`.

## [0.0.0] — 2026-08-19

The vault architecture, with its dependencies restored: six contracts, ERC-1967 proxy, ERC-7201
namespaced storage, `CREATE2` addresses, EIP-1153 transient reentrancy guards, and the nine-step
onboarding flow. See `README.md` for the shape.
